# 酒馆资料管家

在 SillyTavern 里搜索、批量备份和删除资料，不需要打开宝塔管理文件。纯前端第三方扩展，使用当前酒馆账号的原生接口，不需要后端插件或额外服务。

**目标版本：SillyTavern 1.19.0。** 清单设置了最低版本 1.19.0；其他版本请先在测试实例验证。

## 功能

| 分类 | 支持范围 |
| --- | --- |
| 角色卡 | 搜索、批量导出、删除、恢复；保留聊天文件；恢复时保留原文件名，并尽力恢复收藏状态和最近聊天指针 |
| 世界书 | 按世界书文件批量导出、删除和恢复，不是批量删除书内条目 |
| 预设 | 仅显示酒馆“对话补全预设”下拉框对应的已保存预设，名称和数量使用同一份服务器数据 |
| 主题 UI | 已保存的主题 JSON，包含主题内的自定义 CSS |
| 正则 | 全局正则；点击“扫描内置正则”后，包含所有可读角色卡和预设里的正则，并显示所属资料 |
| 本地回收副本 | 删除前自动保存副本；支持批量恢复、下载、导入备份与清理 |

- 名称搜索、排序、全选筛选结果、反选、分页、内容预览。
- 搜索或切换分类时清空选择，避免误操作隐藏项目。
- 当前角色、群聊成员、当前选择的预设、当前主题与已知世界书绑定受到保护。它们的内置正则同样受到保护；可切换使用对象后操作。
- 点击 ☆ 手动保护资料，再次点击 ★ 取消。手动保护保存在当前浏览器，按账号区分。
- 删除时显示具体清单，输入“删除 N”后才会执行。
- 每项先完成本地备份，再执行服务器删除；备份失败则该项不删除。逐项显示结果，单项失败不会终止其他项目。
- 可停止尚未开始的操作，正在处理的一项会先完成。
- 操作后关闭面板会刷新酒馆，更新原生界面和内存缓存。
- 中文界面，适配桌面和手机浏览器。

## 通过 GitHub 安装

先把本目录内容发布到自己的 GitHub 仓库，确保仓库**根目录**直接有 `manifest.json`、`index.js`、`style.css`、`api.js`、`core.js`、`storage.js` 和 `ui.js`。不要把整个目录再套在仓库下一级。

1. 打开 SillyTavern → **扩展** → **安装扩展**。
2. 粘贴这个插件的 GitHub **仓库主页链接**，例如 `https://github.com/你的用户名/sillytavern-library-manager`（这是格式示例，需要换成实际发布地址）。
3. 安装完成后刷新酒馆。
4. 在扩展设置中展开 **资料管家** 折叠栏，点击 **打开资料管家**。

更新时在酒馆的扩展管理里检查更新并更新。本插件声明 `auto_update: true`，是否自动执行仍由酒馆的全局扩展更新设置决定。手工复制 ZIP 文件安装不会自动建立 Git 订阅。

## 第一次使用

1. 在一个分类里搜索并勾选资料；可以先点击 **导出选中**，确认设备已经保存备份文件。
2. 点击 **删除选中**，核对清单并输入确认文字。受保护项会从删除清单中排除。
3. 在 **本地回收副本** 中查看结果。恢复时跳过同名资料，不覆盖现有文件。
4. 操作结束后关闭面板，让酒馆刷新。处理资料时不要同时在其他标签页、设备或宝塔中修改同一批资料。

## 备份与恢复的边界

- **不是服务器回收站。** 原文件会通过酒馆原生接口删除，恢复副本在浏览器 IndexedDB 中。更换浏览器、无痕会话结束、清除网站数据或浏览器自动回收存储，都可能使副本不可用；重要副本请下载到设备。副本不会自动上传到 GitHub。
- 副本按站点来源和酒馆账号分区。浏览器本地分区不等同于加密；不要把同一个浏览器配置文件当作不同用户之间的安全隔离。
- 角色卡备份采用官方 PNG 导出接口，包含头像、卡片文本及卡内嵌入的扩展内容。**聊天文件、群聊定义、外置立绘、语音、向量库和其他插件独立目录不在备份范围。** 角色恢复使用原文件名，便于重新找到保留下来的聊天；导入流程可能重新生成创建时间等元数据。
- 删除角色时明确传递 `delete_chats: false`。不自动删除聊天，也不清理角色标签映射、外置资源或其他插件引用。
- 世界书保护基于当前可读的全局、聊天、人设、角色及额外书籍绑定；浅加载角色、未打开的聊天和其他扩展的引用不保证全部被发现。删除世界书不会自动改写这些引用。
- “主题 UI”指酒馆主题文件。独立扩展、脚本注入的界面、背景图和可移动面板布局预设不在此版批量删除范围；1.19.0 没有对应的官方布局删除接口。
- 正则按所属资料和标识处理，修改过或重复标识的项目会被拒绝。无标识的旧正则按内容匹配；完全相同的重复项需要先在原生编辑器处理。
- 导入/恢复备份会重新引入其中的主题 CSS 和正则等内容，仅恢复你信任的备份。
- 请求中断时服务器可能已经完成操作，面板会提示核对服务器，同时保留已有副本。没有服务器事务或跨设备互斥；同名检查不能消除其他设备在检查之后同时写入的竞争。
- 当浏览器支持 Web Locks 时，同一浏览器中的插件写入任务互斥；旧浏览器或非安全 HTTP 环境可能没有该能力。

## 测试与开发

无需构建或安装运行时依赖，文件直接由 SillyTavern 加载。测试资料都是合成资料，未读取或修改真实酒馆资料。

```sh
npm run check
npm test
```

浏览器流程测试需额外安装 Playwright 开发工具：

```sh
npm install --no-save playwright
npx playwright install chromium
node tests/browser.mjs
```

测试覆盖先备份后删除、备份配额失败、保留聊天、同名冲突、请求失败、内容变化检测、全局/内置正则、备份校验、停止操作、恢复顺序、IndexedDB 持久化和账号分区、界面导入导出、手机布局以及实际扩展入口路径。

接口实现对照 SillyTavern 官方 `release` 分支中标示为 1.19.0 的源码：`src/endpoints/{characters,worldinfo,presets,themes,settings}.js` 和对应前端模块。自动化使用模拟酒馆接口，**尚未在你的实际部署中验证**；首次使用建议用少量可丢弃的测试资料完成“备份 → 删除 → 恢复”检查。

## 文件结构

```text
manifest.json   酒馆扩展清单与更新元数据
index.js        酒馆入口与上下文适配
api.js          原生接口、备份、删除、恢复
core.js         分类、保护、备份格式与批处理逻辑
storage.js      按账号分区的 IndexedDB 副本库
ui.js           中文管理面板
style.css       桌面和移动端样式
tests/          合成数据与自动化测试
```
